# PesaPay-app

Fast, secure QR-to-M-Pesa payment mobile and web application built with React Native and Expo.

## Features
- **Smart Modern UI**: Cyber-mint neon aesthetic with glowing aim target and laser scanning animation.
- **Responsive Layout**: Adapts gracefully across small phones, tablets, and desktop browsers.
- **Safaricom Till QR Scanning**: Camera QR resolution with simulated offline protection.
- **Direct Backend Integration**: Connects to the PesaPay Express API for instant merchant resolution and STK Push.
- **EAS Build Ready**: Configured with `eas.json` for standalone Android/iOS production builds.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run in Web
```bash
npm run web
```

### 3. Run in Expo Go (Mobile)
```bash
npm start
```

### 4. Build with EAS
```bash
eas build --platform android
```
